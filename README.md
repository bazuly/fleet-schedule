# fleet-schedule

План транспорта и заявок на перевозку — замена Google-таблицы. Слева машины и водители,
справа график по дням; ячейки редактируются как в Excel. «Нераспределенное» и «Заборы продукции»
вынесены в плавающие окна, чтобы не перегружать основной график.

## Стек

- **backend** — Rust (axum, sqlx), PostgreSQL, WebSocket для синхронизации между пользователями.
- **frontend** — Next.js + TypeScript, собственная виртуализированная таблица, состояние в zustand.
- Всё запускается через `docker compose`.

## Запуск

```bash
cp .env.example .env        # при необходимости поменять пароли
docker compose up -d --build
```

- приложение: http://localhost:3000
- API: http://localhost:8080/api
- первый вход: `admin` / `admin` (задаётся `ADMIN_LOGIN` / `ADMIN_PASSWORD` в `.env`, создаётся только на пустой базе)

Новых пользователей добавляет администратор на странице «Пользователи».

## Разработка без контейнеров

```bash
docker compose up -d db
cd backend && cp .env.example .env && cargo run      # :8080, миграции применяются при старте
cd frontend && npm install && npm run dev            # :3000
```

## Работа с таблицей

| Действие | Как |
| --- | --- |
| Выделить диапазон | протянуть мышью, Shift+клик, Shift+стрелки |
| Строка / столбец целиком | клик по номеру строки / по дате |
| Ввод | начать печатать (заменяет), Enter / F2 / двойной клик (правка) |
| Подтвердить ввод | Enter (вниз), Shift+Enter (вверх), Tab / Shift+Tab (вбок), Esc — отмена |
| Перенос строки в ячейке | Alt+Enter или Ctrl+Enter |
| Копировать / вырезать / вставить | ⌘/Ctrl + C / X / V — совместимо с Excel и Google Sheets |
| Отменить / повторить | ⌘/Ctrl+Z, ⌘/Ctrl+Shift+Z или Ctrl+Y |
| Очистить | Delete / Backspace |
| Автозаполнение | потянуть за синий квадрат в углу выделения |
| Прыжок к краю данных | ⌘/Ctrl + стрелка |
| Заливка | кнопка «Заливка» в панели |
| Строки | правый клик: вставить выше/ниже, переместить, удалить; «+ Добавить строку» внизу |

Задание из окна «Нераспределенное» переносится в график так: вырезать (⌘X) в окне, выделить
ячейку в графике, вставить (⌘V) — в окне ячейка очистится. Окна можно двигать, менять размер,
сворачивать (двойной клик по заголовку) и скрывать; положение запоминается. Флажок «синхронно»
прокручивает окна по датам вместе с графиком.

## Устройство

```
backend/
  migrations/   схема БД: users, sessions, schedule_rows (panel: main | unassigned | pickups), cells
  src/          auth, rows, cells (пакетная запись через UNNEST), ws (broadcast изменений)
frontend/src/
  components/Grid.tsx      таблица: виртуализация, выделение, редактор, буфер обмена, автозаполнение
  components/Workspace.tsx раскладка: тулбар, строка формул, график и плавающие окна
  lib/store.ts             данные, оптимистичные правки, undo/redo
  lib/realtime.ts          WebSocket с переподключением
```

API: `GET/PUT /api/cells?from&to`, `GET/POST/PATCH /api/rows`, `DELETE /api/rows/{id}`,
`/api/auth/*`, `/api/users`, `GET /api/ws?token=` (события `cells`, `rows`, `row_deleted`).
